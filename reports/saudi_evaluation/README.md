# Saudi External-Domain Evaluation

This folder contains preliminary external-domain testing of the final RoadGuard model on Saudi road images.

Purpose:
- Check whether the RDD2022-trained model produces road-damage detections on unseen Saudi imagery.
- Review qualitative predictions and failure cases.

Important:
- The Saudi dataset uses a different annotation and class scheme from RDD2022.
- Current Saudi results should not be interpreted as directly comparable four-class mAP.
- Saudi-specific evaluation is still under review.

The Saudi dataset was not used for training.
